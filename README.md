# Nigel Appiah — Developer Portfolio

A responsive portfolio for web developer Nigel Appiah. The site presents selected work, practical skills, a learning journey, and verified project demos through a warm, premium interface.

## Features

- Semantic, accessible single-page structure
- Responsive navigation and project layouts
- Transparent Memoji hero artwork with a lightweight CSS gradient treatment
- Glass navigation, restrained scroll reveals, and reduced-motion support
- Featured Attendance Management System gallery with five real interface screenshots
- Project presentations for Londus Mart and DE Clothing
- Contact form that opens a pre-filled email draft without pretending to use a backend
- Keyboard-visible focus states
- Search and social sharing metadata
- Lightweight, framework-free implementation

## Technologies

- HTML5
- CSS3
- JavaScript

## Run locally

No build step or development server is required.

1. Download or clone the repository.
2. Open `index.html` in a modern browser.

You can also use a local static server if you prefer, but the site does not depend on VS Code Live Server.

## Deployment

This is a static site. On Netlify, use the repository root as the publish directory and leave the build command empty.

The final portfolio URL has not yet been supplied. Add it to this README, `robots.txt`, `sitemap.xml`, and the Open Graph metadata once the production domain is known.
